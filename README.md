# خبير البرومبتات - دليل بناء المواقع والتطبيقات

موقع تعليمي تفاعلي باللغة العربية لتعلم كيفية بناء المواقع والتطبيقات باستخدام البرومبتات والذكاء الاصطناعي.

## 🎨 المميزات

- **تصميم داكن مع لمسات برتقالية متوهجة**: واجهة مستخدم عصرية وجذابة
- **روبوت تفاعلي ثلاثي الأبعاد**: يتفاعل مع حركة الماوس ويظهر في جميع الصفحات
- **رسوم متحركة سلسة**: باستخدام Framer Motion لتجربة مستخدم ممتعة
- **تصميم متجاوب بالكامل**: يعمل بشكل مثالي على جميع الأجهزة
- **دعم كامل للغة العربية**: مع اتجاه RTL وخطوط عربية جميلة

## 🚀 البدء السريع

### المتطلبات

- Node.js 24 أو أحدث
- npm أو yarn

### التثبيت

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على [http://localhost:3000](http://localhost:3000)

## 📦 التقنيات المستخدمة

- **Next.js 16**: إطار عمل React للتطبيقات الحديثة
- **TypeScript**: للحصول على كود آمن ومنظم
- **Framer Motion v11**: للرسوم المتحركة السلسة
- **CSS Modules**: لتنسيق مكونات معزولة
- **Google Fonts**: خطوط Cairo و Tajawal للعربية

## 🎯 الصفحات

- أمثلة كود متوهجة
- بطاقات تفاعلية
- أزرار التنقل (السابق/التالي)
- مؤشرات التقدم

## 📝 ملاحظات مهمة

### إصدار Framer Motion
المشروع يستخدم **Framer Motion v11** للتوافق مع الكود الحالي. إذا واجهت مشاكل:

```bash
# إلغاء تثبيت الإصدارات الحالية
npm uninstall framer-motion motion-dom

# تثبيت الإصدار 11
npm install framer-motion@11
```

### الاتجاه RTL
جميع الصفحات تدعم الاتجاه من اليمين لليسار (RTL) تلقائياً. تأكد من استخدام:
- `direction: rtl` في HTML
- خصائص CSS المناسبة للعربية
